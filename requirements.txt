# Python environment for scripts/ — pinned so the snippet render pipeline is
# reproducible.
#
#   python3 -m venv path/to/venv
#   path/to/venv/bin/pip install -r requirements.txt
#
# Direct dependencies are weasyprint, beautifulsoup4, PyYAML and pillow; the
# rest are transitive. This is a full freeze rather than a direct-dependency
# list because WeasyPrint's rendering depends on its own dependency versions
# (pydyf writes the PDF, tinycss2 parses the CSS), so a card can shift
# without weasyprint itself changing.
#
# WeasyPrint also binds to system libraries that pip cannot pin — pango,
# harfbuzz and fontconfig, installed here via Homebrew. Text metrics can move
# when those are upgraded, independently of anything in this file.
#
# Not included: scripts/ocr_image.py and scripts/ocr_translate.py import
# google-cloud-vision and google-cloud-translate, which are not installed in
# this environment.
